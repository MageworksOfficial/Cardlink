# Feedback · CardLink 7.8 Beta
Thank you for helping improve CardLink. Report bugs, confusing controls, usability problems, networking trouble, platform issues and feature requests.

The public repository is not created yet. Keep a local report until the maintainer supplies the real project/Issues URL. Settings → About will enable its project button once configured.

Include:
- Version shown on the title screen, OS/version, and Online or Offline mode.
- What you wanted to do; numbered steps; expected result; actual result.
- Reproducibility and whether restarting changes the result.
- For networking: Host/Guest, direct/relay if known, room-code behavior, Card Sync and reconnect involvement. Do not include an active room code.
- Cropped screenshots or relevant redacted log excerpts if useful.

Never include passwords, private keys, API tokens, room credentials, private personal information, full user-data folders or other players' private cards. Review logs before attaching them. Serious vulnerabilities belong in a private report under [Security](SECURITY.md), not a public issue.
