# Table selection assets

The selection screen reuses the existing clean title background and CardLink logo. The user approved reuse of existing clean tiles/assets. No generated image provider was used.

`back_exact.png`, `settings_exact.png`, and `exit_exact.png` are exact navigation crops supplied in `CardLink-Preset-Selection-Assets-Corrected.zip`. The flattened commercial-game preset tiles were not imported. The two large selectable panels are drawn by the existing Godot UI system with CardLink Standard / Build Your Own text.
