# CardLink 7.8.1 Beta
CardLink is still in active development. You may encounter bugs, rough edges, or features that are still being improved. Your feedback is deeply appreciated and helps make CardLink better for everyone. If something feels confusing, breaks, or could work better, please let us know. Thank you for testing CardLink.

Build a deck from your own images, spread cards across a flexible table, invite a friend with a room code, or test both sides offline. Tokens, counters, life, dice and history stay manual. Private zones, reveal requests and Card Sync help you share a table; multi-face cards and optional Scryfall/decklist importing expand what you can bring.

Windows: extract the complete ZIP, keep EXE/PCK together and launch. macOS: extract the app; ad-hoc builds may need Gatekeeper approval. Native Mac validation is still pending.

Online: Host Game → privately share code → Join Game. Offline: choose Offline Mode and load your decks. See PLAYER_GUIDE.md.

Read KNOWN_ISSUES.md before testing, especially the unverified distant multi-face acceptance and native Mac tests. Report version, platform, mode and reproduction steps using FEEDBACK.md. Do not send secrets or personal data.

The current online server is provided for testing and community use. Its uptime and long-term availability are not guaranteed. Multiple selectable community servers, volunteer relay operators, donated capacity and automatic fallback are future roadmap ideas, not current features.

This package is for local review until artwork and reporting-channel review is complete. No public repository/release exists yet.

## 7.8.1 Online preparation hotfix
Host or Join, load both decks, then press **Start Match** immediately. Missing artwork uses placeholders. Either player can choose **SYNC MISSING CARDS** while playing; verified images appear in place. Only the selected decks’ definitions and referenced face images are shared automatically. Hidden-zone inspection still has its separate permission flow.
