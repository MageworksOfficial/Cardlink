## 02. Welcome to your table

Bring your own cards. Build a deck. Make room for a game that works the way your group wants to play.

Screenshot: table-overview.png — Original demo cards used throughout this guide; your own collection will look different.

1. CardLink is a free, open-source card sandbox. Import custom images, save decks and play offline, over a local network or through an internet room.
2. You move the pieces and agree on the rules. CardLink tracks hands, piles, counters and shared actions; it generally does not enforce card text, costs or legal plays.
3. Start with the standard table. Later, Build Your Own lets you create spaces for different games and formats.

> New here? Follow pages 3-18. Playing with a friend? Go to pages 32-41. Building a custom table? Start on page 42.

## 03. Play in 5 Minutes

Try a few cards offline first. You can learn the table before inviting anyone.

Screenshot: deck-builder.png — Deck Builder detail crops. A small saved deck is enough to explore drawing and placement.

1. Open CardLink and choose OFFLINE MODE. Use Card Library to import a few images you have permission to use (page 9), or import a ZIP (page 10).
2. Open Deck Builder, add your cards, set quantities and save a named deck (page 12).
3. Load the saved deck onto a standard table. Draw with D and drag a hand card onto the battlefield.
4. For two-player play, choose ONLINE MODE instead. Connect, load both decks, finish Card Sync and press START MATCH when it turns gold.

> The five-minute path assumes your images or deck are ready. Offline play does not need the online START MATCH handshake.

## 04. Install & launch

Extract the entire download before opening the game. Keep the release files together.

1. Windows: extract the Windows ZIP to a folder you control. Keep CardLink.exe and CardLink.pck together, then open CardLink.exe.
2. Mac: extract the Mac ZIP and open Cardlink.app. The current Universal Beta contains Intel and Apple Silicon executables.
3. The Mac Beta is ad-hoc signed and not notarized. If macOS blocks it, verify the download and use the normal Open / Privacy & Security approval offered by macOS. Do not disable security protections.

Windows | ZIP → Extract → CardLink.exe + CardLink.pck
--- | ---
Mac | ZIP → Extract → Cardlink.app
Keep | Release documentation and third-party notices

> Native Mac human testing remains pending for this corrected release candidate. The exported bundle was checked on Windows; that is not a native Mac test.

## 05. Choose your starting point

The title screen keeps the two ways into CardLink easy to find.

Screenshot: title-fresh.png — Current V0.8.5.1 title screen.

1. ONLINE MODE opens the path to connecting with another player. You can use a room code or Advanced LAN/IP.
2. OFFLINE MODE opens local play and preparation. Build a collection, make a deck or try a custom table without a server.
3. Deck Builder has a direct title-screen shortcut. New Match, Resume Match and Controls offer other quick routes. SETTINGS adjusts preferences; EXIT closes the application.

> Start offline if you just want to experiment. Your local cards and saved decks are reusable when you play online.

## 06. Three ways to play

Choose the connection that matches where your opponent is.


Mode | What you need | Best for
--- | --- | ---
Offline | One computer; no internet | Learning, deck testing and custom tables
Advanced LAN/IP | Two clients on the same local network; host IP and matching port | Same-Wi-Fi or same-network play; no public relay or internet required
Online room code | Internet and an available CardLink room service/relay | Friends in different locations

> LAN is a local-network connection. Room codes are the internet service. They are different paths, even though both begin from Online.

## 07. Make CardLink comfortable

Open SETTINGS from the title screen. The panel scrolls, so some preferences sit above or below the pictured area.

Screenshot: settings-corrected-v0851.png — Settings, scrolled to the card-back and navigation controls.

1. Set Player Name for the name other players see. Review hidden-zone preferences together before a game.
2. Choose a default Card Back. Table layout & display… controls presentation; Key Bindings… lets you inspect or change supported shortcuts.
3. Use Integrations / Optional Catalog… for optional card search. Reduce Motion keeps readiness cues visible while reducing animation.

> This is the corrected Settings capture. A gold START MATCH button still means ready when Reduce Motion is enabled.

## 08. Your Card Library

The Card Library is your collection of reusable card definitions. A deck chooses from that collection.

Screenshot: collection.png — The collection toolbar, search field and card thumbnails. Select a card for its details.

1. Open Card Library and search by name or use tags and sorting to narrow the thumbnails.
2. Select a card to inspect its image and metadata. Edit names and tags when you need a more useful collection.
3. Use Add Custom Card, Import ZIP Deck or the optional online search to bring in cards. Then choose them in Deck Builder.

> Deleting a match copy is different from deleting a stored definition. Be careful with collection deletion: saved decks reference these cards.

## 09. Import your own card

Use an image you created or have permission to use. A clear, straight card image works best.

Screenshot: import-card.png — Preview the crop before confirming the import.

1. In Card Library, choose Add Custom Card, then Choose Image. Select the image file.
2. Enter a useful card name. Adjust the crop or Fit/Fill controls while watching the preview; keep important text inside the frame.
3. Confirm Crop & Import. The card becomes available in the Card Library and Deck Builder.

> Gameplay images are normalized to the standard card shape. To make another face of the same card, use Add Another Face after the first import (page 13).

## 10. Bring a whole ZIP deck

Bulk import turns a folder of images inside a ZIP into a collection and a saved deck.

Screenshot: archive.png — A three-image demo archive, previewed before any import is committed.

1. Choose Import ZIP Deck and select the archive. Nested folders are scanned for supported PNG, JPG, JPEG and WebP images.
2. Review the preview: new, existing and changed cards, unsupported files and unusual image shapes. Choose global Fit or Fill if needed.
3. Import a new deck, or explicitly update a matching imported deck. Review additions, removals, quantities and changed artwork first. Cancel leaves the preview uncommitted.

> Repeated imports reuse identical normalized images and matching card definitions. ZIP is supported; RAR is not part of this guide’s supported workflow.

## 11. Optional Scryfall search

For Magic card lookup, enable the optional catalog in Integrations. CardLink remains usable without it.

Screenshot: scryfall-results.png — Live optional-provider search: query and filters above, selected result and Add to Library below.

1. Open Online Card Search. Enter a name or Scryfall query and use color, type, format, set or other filters to narrow results.
2. Select a result. Choose Printing helps you pick the version you want; results load small previews rather than every full-size image.
3. Choose Add to Library to import the selected printing and its available faces. Imported cards become part of your local collection.

> CardLink does not own commercial card art or text. Third-party material remains subject to its owners’ rights and terms. Scryfall is an independent optional service.

## 12. Build a deck you can reuse

A saved deck stores card choices and quantities. It does not need a second copy of every image.

Screenshot: deck-builder.png — Detail crops: collection and deck entries, quantity controls, then Save / Rename and Load.

1. Open Deck Builder. Search the available collection, select a card and choose Add selected card.
2. Select a deck entry to change its quantity, remove it or mark it as a leader. Check the total count as you work.
3. Give the deck a name and Save. Use Load to reopen it; Rename, Duplicate and Delete manage saved deck files.

> Leaders are optional and can include more than one card. CardLink does not automatically enforce a format’s deck-building rules.

## 13. One card, several faces

A multi-face definition links its images to one card. Changing face keeps the same piece on the table.

Screenshot: multi-face.png — An original two-face demo definition: Beacon / Moon.

1. Import the first face, then use Add Another Face to attach the next image. Give each face a clear name.
2. In Deck Builder, Next Face previews the linked faces without creating extra deck copies.
3. On the table, select the card and choose Change Face / Next Face in Card Actions. Repeat to cycle through its available faces.

> Changing face is not the same as hiding a card. Face-down presentation uses a card back. Change Card Face has no default keyboard binding; you may assign one in Settings.

## 14. Load your deck

Load a saved deck when you are ready to put its pieces on the table.

Screenshot: decks-loaded.png — Offline demo: two loaded libraries and separate Leader areas.

1. Use the deck-loading controls to choose your saved deck. Check the name and total before loading.
2. Choose whether designated leaders begin outside the main library. They appear in the Leader area rather than being shuffled with the other cards.
3. Check the library count and selected card back. In online play, both players load their own decks and wait for readiness.

> Loading creates match copies. Moving those copies around the table does not rewrite your saved deck list.

## 16. Hands & hidden information

Your hand shows your cards. Online, the other player normally sees card backs and a count.

Screenshot: online-hand.png — Two local LAN clients: your hand is visible, while the remote hand uses backs.

1. Press X or click Hands: Shown [X] to hide or show the hand areas. This changes your view; it does not discard the cards.
2. Hover your own hand card to inspect it. Right-click for Card Actions, then choose Reveal or Hide / Face Down. An eye badge means the opponent can currently see that identity.
3. Revealing one card does not reveal the rest. The reveal follows that card when moved; shuffling a library clears the reveal state of cards in that library.

> CardLink is an honor-system table with deliberate inspection tools. Agree before inspecting hidden zones. Offline playtest visibility can differ from online privacy.

## 17. Ready? Start Match

The top-bar START MATCH button tells you when the online table is ready.

Screenshot: start-gold.png — Dim, ready and active: actual top-bar crops from an isolated LAN session.

1. Dim: preparation is incomplete. Both players must connect, choose decks and complete the required Card Sync/readiness steps.
2. Gold: both decks are ready. Press START MATCH to begin the shared match.
3. MATCH ACTIVE: the match has started. You can draw and play using the tabletop controls.

> Reduce Motion preserves the gold ready state without animation. The text changes as well, so readiness is not communicated by color alone.

## 18. Draw, or play the top card

Drawing moves a card into your hand. Playing the top card moves it directly to the battlefield.

Screenshot: library-actions.png — The library menu groups draw, placement, reveal and ordering tools.

1. Press D to draw one from your local library. Open Library Actions for Draw N when you need several.
2. Press Ctrl+D to place the top library card beside the deck on the battlefield. Move it from there to its final position.
3. Use the face-down entry option in Hand/Library actions when cards should enter the battlefield hidden. Check that option before placing cards.

> Ctrl+D performs a placement; it is not an automatic-draw toggle. In a custom table, draws use the active seat’s appropriate primary pile (page 44).

## 19. Play like a physical table

Drag a card from your hand onto the battlefield. Place it wherever your game needs it.

Screenshot: multi-select.png — Independent pieces can be selected and moved as a group.

1. Hover to inspect, then drag to move. Use the mouse wheel to zoom and middle-mouse drag or arrow keys to pan.
2. Select several hand cards, release Ctrl/Shift and drag a selected card to play the group. Selected battlefield objects can also move together.
3. Use Change Controller when control changes. Owner and controller are separate: a card can remain owned by one player while another controls it.

> CardLink does not decide whether a play is legal. Talk through unusual actions just as you would at a kitchen table. R resets the view; it does not reset the match.

## 20. Tap, reveal or hide

Card Actions lets you change a piece’s presentation without automating its rules.

Screenshot: card-actions.png — Card Actions includes tap, movement, face and counter controls; scroll for more actions.

1. Select a battlefield card and press Q, or double-click the card, to toggle Tap / Untap.
2. Right-click to open Card Actions. Use Reveal or Hide / Face Down as appropriate for your game.
3. A revealed library top uses its card face. A hidden top uses the selected back. Shuffling removes public reveal state from that library.

> Double-clicking an ordinary battlefield card toggles tap. Tokens use their properties interaction. Right-click is the reliable route to the action menu.

## 21. A place for every piece

Use zones to keep the game understandable. Zone changes are manual actions.


Zone | Purpose
--- | ---
Library | An ordered draw pile; top and bottom matter
Hand | Cards held by a player; hidden from the opponent by default
Battlefield | Free placement of public or face-down pieces
Graveyard | Discarded or destroyed normal cards
Exile | A separate holding area for cards removed from other zones
Leader | Optional commanders or other designated leaders

> Normal-card Delete sends a match copy to its owner’s graveyard. It does not delete the stored Card Library definition. Tokens leaving the battlefield are removed.

## 22. Work with your library

Open Library Actions from the pile or menu. Choose the target library and amount before acting.

Screenshot: library-actions.png — Scroll the Library Actions panel to reach the full set of manual tools.

1. Draw N puts cards into hand. Mill N sends top cards to graveyard; Mill from Bottom takes them from the other end.
2. Reveal Top N inspects a limited group. View/Search opens the visual gallery; an unrestricted search shuffles that library when you finish.
3. Scry lets you inspect top cards, reorder them and send chosen cards to the bottom. Surveil sends chosen cards to graveyard instead. Confirm when the remaining order is right.
4. Use Top, Bottom or Nth placement for selected cards. N = 1 means the top or bottom position. Opponent-private operations may require the other player’s participation.

> Scry, Surveil and Reveal Top N preserve the intended order; they do not trigger the automatic shuffle used after unrestricted library search.

## 23. Make a token

Tokens are independent battlefield objects, with their own name, art and controller.

Screenshot: token.png — Creating an original Scout Token with 2 power and 2 toughness.

1. Right-click empty battlefield space and choose Create Token, or use T when appropriate. Enter a name and optional power/toughness.
2. Choose an optional image, owner and controller, then create it. Double-click the token to open its properties and revise name, stats or art.
3. Use Duplicate Token to copy its appearance and values as a new match instance. Move or edit the duplicate independently.

> A token that leaves the battlefield for hand, library, graveyard or exile is destroyed instead of being stored there. Delete also removes it.

## 24. Count what matters

Use an attached counter for a card’s value, or a standalone counter for something on the table.

Screenshot: counter.png — A standalone Energy counter can be edited independently of any card.

1. Select a card or token, then use Counter actions to add or remove its counters.
2. Right-click empty space to Create Counter. Give the standalone object a label if helpful, then set or adjust its value.
3. Drag standalone counters into place. Open their properties to increase, decrease, set or delete them.

> Counters record numbers. They do not pay costs or trigger card text automatically. C opens the context-appropriate counter action.

## 25. Track Loyalty clearly

Loyalty is a named value on a selected card. You control when and how it changes.

Screenshot: loyalty.png — The Loyalty dialog with a value of zero.

1. Select the card and open its Loyalty control from the available card/counter actions.
2. Use +1 or −1 for small adjustments, or enter an amount and use Add / Set Loyalty.
3. Set the value to zero when needed. Zero stays visible; remove the Loyalty counter explicitly if you no longer want it.

> Reaching zero does not automatically destroy or move the card. Apply your game’s rules manually.

## 26. Life, turns & table tools

The shared table has helpers for routine bookkeeping. You still decide what each result means.

Screenshot: tools.png — Compact Tools panel: rolls, coin and calculator.

1. Use the life controls to adjust a player’s life. Life changes are recorded in Match History.
2. Press N for End Turn. The active player changes and turn tracking advances; cards do not automatically untap or draw.
3. Open Tools for D6, D20, custom dice, a coin flip or the simple calculator. Dice and coin results are recorded; Match History (M) lets you review events.

> Use reasonable custom dice counts and sizes. Do not treat the calculator or turn counter as a rules engine.

## 27. Select more than one

Build a selection when you want to move or act on several pieces together.

Screenshot: multi-select.png — Gold outlines identify the selected pieces, not their controller or legality.

1. Drag a rectangle over empty battlefield space to select intersecting cards, tokens and standalone counters.
2. Ctrl-click or Shift-click supported objects to add or remove them. The selection outline shows what is included. Click empty space to clear it.
3. Drag one selected battlefield object to move the group. In your hand, Ctrl/Shift-click cards, release the modifier and drag a selected card onto the battlefield.

> Right-click a selected group for bulk actions. Normal-card Delete goes to owner’s graveyard; token and standalone-counter Delete removes those objects.

## 28. Arrange selected pieces

Select battlefield objects, right-click and open Arrange. Each object stays an independent piece.

Screenshot: arrange.png — Enlarged Arrange submenu. Open it from the selected group’s right-click menu.


Stack | Put the selection into a compact overlapping pile
--- | ---
Fan | Overlap pieces in a readable straight spread
Horizontal | Line up across the table
Vertical | Line up down the table
Distribute | Space evenly along the selection’s main direction
Spread Out | Separate pieces into a spaced row

> These are layout tools, not game-state groups. They do not merge cards. Fan uses a straight overlapping arrangement, and Spread Out does not restore earlier positions.

## 29. Give your deck a back

A deck back keeps hidden cards recognizable as pieces without showing their identity.

Screenshot: deck-back.png — The deck-back picker applies a back without duplicating gameplay images.

1. Choose a default back in Settings, or open the deck-back picker for the loaded deck.
2. Use the CardLink default, an available preset, a custom color or an image you have permission to use.
3. Apply it for this match, or use Save With Deck where offered to remember it with that deck. Online presentation shares the relevant back appearance.

> A back is presentation, not a second card face. A revealed card can display its face instead of the back; shuffle hides library cards again.

## 30. Set the scene

Change the battlefield background without changing the cards or rules.

Screenshot: background.png — The background editor exposes placement and appearance controls.

1. Open Battlefield Background. Choose the default, a solid/custom color or a permitted custom image.
2. Turn Layout Mode on with L, then press Ctrl+B for Background Edit Mode. Adjust position, size, rotation and opacity; Fit and Fill help frame the image.
3. Lock the background when it is placed. Exit edit mode before returning to card play; use Reset Transform if you want to start positioning again.

> Background editing is separate from L, which toggles Layout Mode for table zones and anchors. Choose a background that leaves cards and zone labels readable.

## 31. Find a function fast

Press Ctrl+F to open Find Cards & Functions in offline or online play.

Screenshot: function-search.png — A library query surfaces relevant search and action entries.

1. Type part of what you want, such as library, token or counter.
2. Choose a result. The search can offer functions and relevant card/zone search actions based on your current context.
3. Select the right target or object before using actions that depend on selection. Close the window or press Esc when finished.

> Function search does not make hidden cards automatically public. A hidden-zone inspection still uses its normal workflow.

## 32. Invite a friend with a code

Room codes use CardLink’s public room service and relay. Both players need internet access.

Screenshot: room-code.png — Current room-code interface. No live room or real participant is shown.

1. Host: choose ONLINE MODE, enter your display name and use Host Game to get a code. Share the code with the person joining.
2. Guest: open Online, enter the host’s room code and choose Join Game.
3. Watch the connection status, choose decks and complete Card Sync. Press START MATCH when both sides are ready.

> Service availability can change. Public Match Save needs a server with current Match Save support; this guide does not claim the production server has been upgraded.

## 33. Play on the same Wi-Fi

Advanced LAN/IP connects directly to another CardLink client on your local network.

Screenshot: advanced-lan.png — Advanced controls captured in a same-computer LAN demonstration.

1. Both players enter Online and open Advanced Network Tools → Advanced LAN/IP. Use the same TCP port.
2. Host: start Host Game and tell the guest your local/LAN IP address. Guest: enter that address and join.
3. If prompted by the operating system, allow CardLink on the appropriate trusted private network. Then load decks and complete preparation normally.

> No public CardLink relay or internet is required on the same local network. 127.0.0.1, pictured here, works only for two clients on one computer; use the host’s LAN IP on two computers.

## 34. Wait for Card Sync

Card Sync helps the two clients obtain the card assets they need to display the game.

Screenshot: card-sync.png — Preparation and Card Sync controls in an isolated LAN session.

1. Load your intended deck and check readiness. If assets are missing, use the available Card Sync controls and allow the transfer to finish.
2. Review missing-card or failed-transfer messages. Retry or choose the offered placeholder behavior deliberately; do not ignore an unexpected missing card.
3. Wait until both clients are ready before starting or restoring a match. Keep compatible originals in your local collection.

> Asset availability is not permission to redistribute someone else’s art. Syncing display resources is separate from revealing a live hand or library order.

## 35. Save Match together

Either player may request a save. Both players must agree before paired local records are created.

Screenshot: save-request.png — The receiving player’s actual approval dialog.

1. Open Menu → Save Match (or Ctrl+S) and enter a name you will recognize later.
2. The other player receives SAVE MATCH REQUEST. They choose ACCEPT or DECLINE.
3. After acceptance, wait for Match Saved on both clients. If saving fails or is declined, do not assume a usable paired save was created.

> Match Save is Beta. One human LAN unsupported-peer warning remains unreproduced. These screenshots show a successful local LAN session, not upgraded production-server support.

## 36. The pieces. The memory.

The decks provide the pieces. The save state remembers the game.

1. Each installation stores a matching paired save. Their shared save_state_id links the two records.
2. Each player’s private hidden state stays in that player’s local record. A save is not a complete deck-and-art distribution package.
3. Keep the compatible original decks, card assets and both installations’ paired records. You need these pieces again to restore later.

Host installation | Original deck + local paired save
--- | ---
Shared pairing | Matching save_state_id and public game state
Guest installation | Original deck + local paired save

> A single player’s save is not enough to resume a paired online match. Keep local data safe when moving or reinstalling CardLink.

## 37. Load a saved match

The original host requests Load Match. The other player approves the restore.

Screenshot: load-list.png — Saved-match picker from the successful local LAN capture.

1. Reconnect using the same original Host/Guest roles and installations. Both players load compatible original decks.
2. Finish Card Sync and any pending transfers. The host opens Load Match and selects the paired saved game.
3. The other player reviews LOAD MATCH REQUEST and accepts. Wait for the restored status on both clients. Decline leaves the current match unchanged.

> If compatibility checks fail, read the message before retrying. A different deck, missing pair or changed installation/role can prevent restoration.

## 38. Return in a new room

You do not need the old room code. You do need the original pair of players and local save records.

1. Create a fresh room/session. Keep the same original host and guest roles.
2. Use the original installations with their paired saves and compatible source decks. Do not rebuild a vaguely similar list and expect it to match.
3. Complete readiness and Card Sync, then let the original host request Load Match. Both players confirm the restore.

New connection | A new room code/session is okay
--- | ---
Same pair | Original installations and Host/Guest roles
Same pieces | Compatible decks + matching local save records

> This is a continuation of the same saved game, not a transferable save for arbitrary opponents. Public rooms still need current server Match Save support.

## 39. Know the Save limits

Plan around these Beta boundaries before relying on a saved online match.


Requirement / limit | What it means
--- | ---
Standard table | Online custom-table Save/Load is not supported yet
Paired local saves | Both installations must retain the matching record
Compatible source decks | The save does not bundle all original decks and assets
Original roles / installations | Keep the original Host/Guest mapping and local identity
Updated public relay | Production Match Save is not assumed available until upgraded
State size limits | Very large or unusual matches may not save successfully

> The local LAN capture succeeded, but it does not erase the unresolved human warning. Keep the exact message and connection mode when reporting a failure.

## 40. Reset for a rematch

Reset Match starts over while keeping the connection. It is separate from resetting the camera.

Screenshot: reset-request.png — The other player’s reset request in the local LAN demonstration.

1. Use Reset Match or Ctrl+Alt+Shift+R. Review the confirmation before requesting an online reset.
2. The other player receives the request and can accept or decline. Do not keep making plays while a reset is being agreed.
3. After both agree, wait for completion. The starting match is rebuilt while both players stay connected. An older/manual match without recorded starting decks may reset to an empty table.

> R alone is Reset View. Ctrl+Alt+Shift+R is Reset Match. These are different actions with very different consequences.

## 41. If the connection drops

Pause play and compare what each client reports. Reconnection is a recovery tool, not a promise that every interrupted action succeeded.

1. Use Retry Now / reconnect when offered. Let synchronization and recovery finish before making more moves.
2. If an action was in progress, agree with your opponent whether it completed. Check the table and history together.
3. If recovery cannot safely continue, follow the displayed reset or restore guidance. Continue Offline and Leave Match are deliberate alternatives, not a repair of the remote game.

1 · Pause | Stop new actions when disconnected
--- | ---
2 · Recover | Reconnect and wait for the clients to settle
3 · Compare | Confirm state together; reset/restore only when appropriate

> Do not repeatedly force actions through a paused connection. Record the warning, mode and last action when reporting a problem.

## 42. Build Your Own table

CardLink Standard is ready for a familiar card game. Build Your Own gives you a layout to shape around a different one.

Screenshot: builder.png — Build Mode with the compact Table Builder drawer open.

1. Choose Build Your Own when you want custom piles, hands, zones, labels or board spaces.
2. Use Build Mode to arrange components, then Play Mode to use the table. Keep the first design small and readable.
3. Use templates to save a reusable setup. A layout template is not a saved in-progress online match.

> Custom tables are still manual sandboxes. Online custom-table Save/Load is not supported in this Beta.

## 43. Use the Table Builder

The drawer brings adding, selecting and editing components into one place.

Screenshot: components.png — Builder controls and example components. Positions are editable.

1. Open the Table Builder in Build Mode. Quick Add creates a component; On Table helps you select something already present.
2. Use selection handles to move or resize the selected component. Keep pile, hand and play areas separated enough to read.
3. Set the useful ownership/seat and component properties, then switch to Play Mode to test drawing, placement and access.

> Build Mode edits the setup; Play Mode uses it. If a normal card action does not do what you expect, first check which mode is active.

## 44. Choose useful components

Start with the pieces your game actually needs. Add more only when they make the table clearer.


Component | Use it for
--- | ---
Deck / pile | An ordered personal pile; designate a primary draw pile
Shared deck | A pile used by the table rather than just one seat
Hand | A seat’s held cards
Discard / zone / leader | Separate destinations for different kinds of pieces
Text / label | Names, reminders and table instructions
Board image / shared area | A visual board or common play space
Tokens / counters | Reusable pieces and numeric trackers

> For custom-table draw/shuffle shortcuts, the active seat’s primary personal pile is preferred, then a suitable shared/single owned pile. Resolve ambiguous pile setups explicitly.

## 45. Save a table template

Templates preserve a reusable table design. They do not replace Match Save.

Screenshot: templates.png — My Tables and import controls; an empty personal template list is shown.

1. Use the template controls to name and save your layout. Reopen it from My Tables when you want the setup again.
2. Import or export a .cltemplate to share a layout. The format is data-only, not executable game logic.
3. Image packaging is optional and starts off. Include images only when needed and when you have redistribution rights. Inspect the loaded layout before playing.

> Templates do not carry private hand identities or library order. Loading a layout is not restoring a running game; existing pile cards may be returned to the battlefield.

## 47. When something gets stuck

Start with the message on screen. Fix one condition at a time, then retry.


Problem | Try this
--- | ---
Cannot connect / LAN fails | Check mode, host IP, matching port and private-network firewall permission
Deck not ready / missing cards | Load the intended deck; finish or retry Card Sync; review missing assets
Match Save unavailable | Use identical current clients, a standard table and settled sync; public rooms need an updated server
Wrong deck / roles / missing pair | Use original roles/installations, compatible decks and both local paired records
Hand seems hidden | Check Hands: Shown [X]; do not repeatedly redraw to find a hidden hand
Mac will not open | Verify the download and use normal macOS approval; do not disable protections
Updater unavailable | Check connectivity or download the reviewed release manually; keep EXE and PCK together

> For a bug report include version, connection mode, host/guest role, the exact message and steps. Remove private card information and personal details from screenshots.

## 48. Privacy is part of play

CardLink tries to keep ordinary hidden information out of normal public presentation. Use its manual reveal tools thoughtfully.

Screenshot: online-hand.png — Normal online hand presentation, demonstrated between local clients.

1. Hands normally show backs to the opponent. Libraries keep their private order unless you intentionally reveal or inspect information through the available tools.
2. A paired save keeps each player’s private state locally. Keep save files and local installation data private.
3. The relay forwards connection/game messages; it is not a rules referee. Deliberate reveal and inspection actions can expose information, so agree on them first.

> This is a Beta honor-system tool, not an absolute secrecy guarantee. Share screenshots, logs, decks and custom art only with appropriate care and permission.
